# MANII CAFE PRO

Full desktop Cafe POS and Management System.

## Features
- Login and roles
- Dashboard
- POS with cart, customer, order type, discount, tax and payment
- Order confirmation and success screen
- Kitchen workflow: Pending → Preparing → Ready → Completed
- Products and sizes CRUD
- Inventory and automatic stock deduction
- Customers and loyalty points
- Employees
- Expenses
- Reports and profit
- PDF receipts
- Settings
- Database backup

## Run

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
